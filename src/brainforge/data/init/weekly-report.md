# Weekly report

## Objective

Summarize what is new or changed in this brain since the previous report.

## Instructions

1. Read the previous report, if one is given.
2. Review the concepts that changed since then, and any other relevant knowledge.
3. Summarize progress, milestone changes, risks, decisions and next steps.
4. Cite every statement. Name missing information instead of guessing.

## Structure

- Executive Summary
- Progress
- Milestones
- Risks and Issues
- Decisions
- Next Steps

## Style

Concise and professional.
